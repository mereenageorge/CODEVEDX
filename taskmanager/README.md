# Task Manager App

A simple Task Manager application built using React and Vite.

## Features

* Add new tasks
* Mark tasks as completed
* Delete tasks
* Filter tasks (All, Active, Completed)
* Responsive and clean UI

## Tech Stack

* React
* Vite
* CSS

## Installation

```bash
npm install
npm run dev
```

## Project Structure

```text
src/
├── components/
├── App.jsx
├── App.css
├── main.jsx
```
