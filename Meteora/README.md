# Meteora Weather App

A modern weather app built using React and OpenWeather API.  
It shows real-time weather details with animated themes for sunny, rainy, cloudy, thunderstorm, and snow weather conditions.

## Features

- Search weather by city
- Real-time temperature
- Humidity and wind details
- 5-day forecast
- Weather icons
- Animated weather effects
- Responsive design
- Error handling

## Tech Stack

- React JS
- JavaScript
- CSS
- OpenWeather API

## Run Project

```bash
npm install
npm run dev
